\section{Manual de usuario}\label{apx:manual-usuario}
\justifying

Este anexo reproduce íntegro el Manual de Usuario mantenido en \code{docs/manuales/usuario/main.tex}. Describe la operación del sistema para los tres tipos de usuario --- \emph{profesor}, \emph{administrador} y \emph{visitante público} --- e incluye las capturas de pantalla tomadas durante la reprueba de despliegue documentada en el Manual de Instalación (Anexo~\ref{apx:manual-instalacion}). Al final del manual se ofrecen las preguntas frecuentes recopiladas durante la fase de validación con datos de demostración.
